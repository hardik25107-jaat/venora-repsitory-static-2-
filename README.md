# Venora — Vercel Deployment Package

This is a self-contained, responsive Venora marketplace demo built with plain HTML, CSS and JavaScript.

## Deploy instantly
1. Open https://vercel.com/drop
2. Drag the whole `Venora_Vercel_Static` folder (or a ZIP of it) into Vercel Drop.
3. Choose a project name such as `venora-marketplace`.
4. Click Deploy.
5. Vercel will give you a live `https://....vercel.app` URL.

No database, npm install, GitHub or environment variables are required for this demo.

## Included functionality
- Responsive Venora landing page
- Search by area/name
- Filter by city and space type
- Space cards with pricing and details
- Favourites stored in browser localStorage
- Booking request flow stored in browser localStorage
- Owner listing form
- Demo dashboard
- Login-style demo flow
- Mobile responsive layout

This version is intentionally dependency-free so it can be deployed directly through Vercel Drop.
